# The Linkroid mark

The Linkroid Mark: PC monitor (Windows) and mobile phone (Android) connected by an energetic interlocking chain link and dynamic flow, symbolizing real-time cross-device continuity.

| File | What it is |
|---|---|
| `icon.png` | The full-color app icon (1024 × 1024 high resolution) |
| `icon-flat.svg` | Scalable vector logo for desktop packages and web |
| `icon-mono.svg` | Monochrome mark for one-color contexts (themed icons, notifications) |
| `icon-512.png` | `icon.png` at 512 × 512 |

The apps render the official mark across platforms:
`desktop/app/src/mark.rs` (Windows executable icon, taskbar, tray and notifications at every
size) and `android/app/src/main/res/drawable/ic_launcher_*.xml` and
`ic_notification.xml`.

Colors (Brand palette): Navy `#052747`, Orange `#FD7200`, Windows Blue `#0070CA`, Android Green `#239B40`.

The name and the mark are covered by the [trademark policy](../../TRADEMARKS.md).
